# Warzish releases

Installable builds of **Warzish**, a strength-first, diabetes-aware fitness app for Android
with Samsung Health integration.

This repository only hosts release files (APKs and a `version.json` used by the app's
built-in updater). The source code is kept privately.

## Install

1. Open the [latest release](https://github.com/ahmadbilal77/warzish-releases/releases/latest) on your Android phone.
2. Download `warzish-x.y.z.apk` and open it. Android will ask you to allow installs from your browser the first time.
3. After that, Warzish updates itself from Profile → Updates.

Requires Android 9 or newer. Warzish is a wellness app, not a medical device.
